# موجِّه الذكاء التكيفي — Adaptive Intelligence Router

**توجيه النموذج × جهد التفكير في Claude Code — مع خطّافات تفرض القواعد فعلاً.**

[English](README.md) · [ما الذي يُفرض قسراً](docs/ENFORCEMENT.md) · [التكييف مع خطتك](docs/CUSTOMIZE.md) · [سجل التغييرات](CHANGELOG.md)

Claude Code يشغّل نموذجاً واحداً لكل شيء افتراضياً: أقوى نموذج عندك ينسّق الجداول ويعيد صياغة الفقرات، فيحرق نافذة استخدامك، ثم يغيب حين يأتي القرار الصعب. هذا المستودع يحوّل جلستك إلى **قائد** يفوّض كل مهمة محدودة إلى أرخص نموذج × جهد ينجزها صحيحة من أول محاولة — ويضيف خطّافين يجعلان القواعد الصلبة مفروضة من الأداة نفسها لا مجرد وعد من النموذج.

## ماذا تحصل عليه

| القطعة | ماذا تفعل |
|---|---|
| **سياسة توجيه مضغوطة** (`policy/`) | وجّه بصعوبة التفكير لا بحجم المهمة؛ أرخص وكيل هو لا وكيل؛ التصعيد بدل البلف؛ عمق التحقق بقدر الخطر. صفحة واحدة — السياسات الطويلة تُقرأ مرة وتُنسى. |
| **١٢ تعريف عامل** (`agents/`) | ١١ عاملاً بصيغة `router-<sonnet\|opus\|fable>-<effort>` لكل منها نموذج وجهد ثابتان، و`Explore`: وكيل استكشاف قراءة فقط على Sonnet حتى لا يرث البحث الروتيني النموذج الأغلى. |
| **حارس التفويض** (`hooks/gate.js`) | خطّاف `PreToolUse` على أداة الوكلاء. يمنع Haiku، ويمنع استدعاء عمال الطاقم بلا `model` صريح مطابق، ويمنع الوكلاء الشاملين الذين يتجاوزون التوجيه. النموذج يرى السبب ويعيد الاستدعاء صحيحاً. |
| **فحص بدء الجلسة** (`hooks/session-start.js`) | يحقن السياسة عند بدء كل جلسة **وبعد كل ضغط للسياق** — اللحظة التي تنسى فيها الجلسات الطويلة — ويحذّر حين يعطّل متغيرُ بيئة التوجيهَ بصمت. |
| **مثبّت ومزيل** (`scripts/`) | على مستوى المستخدم (كل المشاريع)، آمن التكرار، نسخة احتياطية مؤرخة لكل ملف يلمسه، بلا اعتماديات. |

## التثبيت في ٦٠ ثانية

المتطلبات: Claude Code بدعم الوكلاء الفرعيين والخطّافات (مجرّب على ٢٫١٫٢٢٠، سبتمبر ٢٠٢٦) وNode.js ١٨ فأعلى.

```bash
git clone https://github.com/younesbag/adaptive-intelligence-router.git
cd adaptive-intelligence-router
node scripts/install.js
```

ثم **أعد تشغيل Claude Code** — الخطّافات ومجلد الوكلاء الجديد يُقرآن عند بدء الجلسة.

التحقق في أي مشروع:

١. اسأل: «ما سياسة التوجيه النشطة؟» — يجب أن تصف الجلسة الطاقم والقواعد.
٢. اطلب تفويض مهمة «باستخدام النموذج haiku» — يجب أن يمنعها الحارس وتعيد الجلسة التوجيه إلى Sonnet.

الخيارات: `--dry-run` (اعرض ما سيتغير بلا تنفيذ)، `--no-agents`، `--no-hooks`، `--no-policy`، `--force-policy`. المثبّت يحترم `CLAUDE_CONFIG_DIR`.

## كيف يعمل التوجيه

| صنف المهمة | يذهب إلى | لماذا |
|---|---|---|
| ميكانيكي أو محدد بوضوح — إعادة تسمية، تنسيق، اختبارات، توثيق، ترحيل ٥٠٠ ملف بنمط واحد | `router-sonnet-medium` (أو low/high/xhigh بحسب الحاجة) | الكبير ليس الصعب |
| استكشاف قراءة فقط — إيجاد ملفات ورموز واستخدامات | `Explore` | البحث لا يجوز أن يعمل على النموذج الأغلى |
| هندسة صعبة فعلاً — تشخيص معقد، تغييرات عابرة للطبقات، حالة خفية | `router-opus-high` | الصعوبة لا الحجم هي ما يشتري الذكاء |
| معمارية، غموض، أمن/مصادقة/فوترة، ترحيلات هادمة، أدلة متعارضة | `router-fable-high` / `xhigh` | كلفة الخطأ عالية |
| بحث واحد، تعديل صغير، أي شيء أصغر من كلفة تفويضه | **بلا وكيل** — القائد ينفذه بنفسه | التفويض نفسه يستهلك رموزاً وسياقاً |

العمال ملزمون تعاقدياً: يحترمون النطاق ومعايير القبول، وحين تتضح المهمة أصعب من طبقتهم **يوقفون التخمين ويصعّدون** بسبب معلن بدل تسليم بلف مقنع.

## ما الذي يُفرض — وما الذي لا يُفرض

كن صادقاً مع نفسك في هذا قبل الاعتماد على أي إعداد توجيه (التفاصيل في [docs/ENFORCEMENT.md](docs/ENFORCEMENT.md)):

- **مفروض ميكانيكياً بالحارس:** لا Haiku، `model` صريح لعمال الطاقم وExplore، لا وكلاء شاملين (يخففه `ROUTER_GATE_ALLOW_GENERAL=1`).
- **سلوكي، يُعزَّز كل جلسة:** أي طبقة تستحقها المهمة، متى يُصعَّد، كم عمق التحقق. لا يستطيع أي خطّاف قياس صعوبة مهمة — هذا الجزء تحمله السياسة وتذكير الجلسة وحلقة المعايرة.
- **يُكشف ويُبلَّغ لا يُمنع:** متغيرات البيئة (`CLAUDE_CODE_SUBAGENT_MODEL`، `CLAUDE_CODE_EFFORT_LEVEL`) وقوائم النماذج المؤسسية. النموذج المطلوب ليس دليلاً على أنه من نفّذ؛ السياسة تُلزم الجلسة بالتصريح.

## التكييف مع خطتك

الهرمية المشحونة **Sonnet ← Opus ← Fable** بأسماء مستعارة، فهي تتبع ما تحيل إليه هذه الأسماء في حسابك. إن لم تشمل خطتك طبقة (أو حاسبتها منفصلة) فاحذف ملفات عمالها وقصّر سطر الهرمية — يبقى الحارس يعمل. وإن كانت خطتك بنموذج واحد، وجّه على **الجهد** بدلاً من النموذج. التفاصيل في [docs/CUSTOMIZE.md](docs/CUSTOMIZE.md).

## حلقة المعايرة

أي قاعدة توجيه ستخطئ أحياناً. احتفظ بملف محلي للمشروع في `.claude/agent-memory-local/adaptive-router/MEMORY.md`، واكتب سطراً لكل توجيه خاطئ (*المهمة · أُرسلت إلى · كان يجب · لماذا*)، ومرة أسبوعياً اطلب من الجلسة تحويل الملاحظات المتسقة إلى تعديل في السياسة. الموجِّه الذي يتحسن هو الذي يتعلم من أخطائك *أنت*.

## الإزالة

```bash
node scripts/uninstall.js   # --dry-run, --keep-agents
```

يزيل مدخلات الخطّافات ومجلدها والقسم المعلَّم من السياسة، ومن ملفات العمال ما زال مطابقاً لهذا المستودع فقط.
